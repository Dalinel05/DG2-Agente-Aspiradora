# DG_2 - Agente Aspiradora
---
## Descripción
Este proyecto consiste en implementar y mejorar un agente aspiradora en Python. Se parte de un agente con movimientos aleatorios en un entorno 2x2 y se desarrolla una versión mejorada en una cuadrícula 3x3 para organizar la limpieza y controlar el consumo de energía.

## Requisitos
- Python 3
- NumPy
- Matplotlib

## Instalación
Instalar las librerías necesarias:

Ejemplo: 
```
pip install numpy matplotlib
```
